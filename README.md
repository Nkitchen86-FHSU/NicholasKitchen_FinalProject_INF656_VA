# Project Title
 
Final Project - TrackIT
 
## Description
 
TrackIT is an asset management system using the MEAN Stack. There are three user roles (user, tech, admin). Admins can create or modify users and assets, techs can create or modify assets, and users have view-only access to assets. The dashboard shows the overall status for all of the assets. Knowing how many assets are in repair or decomissioned can help companies make business decisions on how they handle their assets.
 
## Getting Started

**You will need to have two consoles open to run the program. One will be for the backend, and the other for the frontend**

### Frontend

Open the frontend console by opening a bash console and run:
```
cd frontend
```

#### Dependencies
 
Please install all the required packages:
```
npm install
```

### Backend

Open the backend console by opening a bash console and run:
```
cd backend
```

#### Dependencies
 
Please install all the required packages:
```
npm install
```

> [!IMPORTANT]
> You will need a JWT_SECRET and MONGO_URI in order for the backend to work.

### Executing program

In the backend console run:
```
npm run dev
```

In the frontend console run:
```
ng serve
```

The frontend console should give you the link to your localhost.
